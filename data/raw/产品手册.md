# XR-2000 智能网关 产品手册

## 1. 产品概述

XR-2000 是面向中型企业边缘节点的智能网关设备，承担协议转换、流量整形与安全接入三项核心职责。
设备出厂预装 XROS 3.x 固件，支持通过 Web 控制台、命令行和 REST API 三种方式管理。

XR-2000 与上一代 XR-1000 的主要差异在于：并发处理能力提升约 4 倍，新增对 gRPC 协议的原生支持，
并引入了基于 eBPF 的流控引擎。如果从 XR-1000 迁移，请参考《升级迁移手册》中的配置对照表。

## 2. 技术规格

| 项目 | 参数 |
| --- | --- |
| 最大并发连接数 | 5000 |
| 整机吞吐 | 20 Gbps |
| 新建连接速率 | 80000 CPS |
| 内存 | 16 GB DDR4 |
| 存储 | 256 GB NVMe SSD |
| 工作温度 | -20 ℃ 至 60 ℃ |
| 存储温度 | -40 ℃ 至 85 ℃ |
| 整机功耗 | 典型 45 W，峰值 80 W |
| 尺寸 | 440 mm × 220 mm × 44 mm（1U） |

注意：最大并发连接数 5000 是在默认流控策略下测得。启用深度包检测（DPI）后，
建议将并发连接数控制在 3000 以内，否则可能出现内存压力导致的连接丢弃。

## 3. 核心配置参数

XR-2000 的所有运行时参数都可以通过配置文件 `/etc/xros/gateway.yaml` 设置，
也可以用 REST API 在线热更新，无需重启进程。

| 参数名 | 默认值 | 说明 |
| --- | --- | --- |
| upstream_timeout | 30 | 上游请求超时时间，单位秒 |
| max_retry | 3 | 上游请求失败后的最大重试次数 |
| retry_interval | 2 | 重试间隔，单位秒 |
| max_connections | 5000 | 最大并发连接数 |
| log_level | info | 日志级别，可选 debug/info/warn/error |
| dpi_enabled | false | 是否启用深度包检测 |
| enable_compression | true | 是否对响应启用 gzip 压缩 |

超时时间的设置需要谨慎：如果 upstream_timeout 小于上游服务的实际处理时间，
会持续产生 E1042 错误并触发重试风暴，反而加剧上游压力。
生产环境的经验值是把它设为上游 P99 延迟的 2 到 3 倍。

## 4. 错误码说明

| 错误码 | 含义 | 常见原因 |
| --- | --- | --- |
| E1042 | 上游连接超时 | 上游服务响应慢、网络抖动、upstream_timeout 设置过小 |
| E2001 | 认证失败 | License 过期、密钥不匹配、系统时钟偏差过大 |
| E3008 | 磁盘空间不足 | 日志文件未轮转、抓包文件堆积 |
| E4017 | 流控规则冲突 | 同优先级规则存在重叠匹配条件 |
| E5003 | 上游连接池耗尽 | max_connections 设置过小或存在连接泄漏 |

### E1042 详细说明

E1042 表示网关在 upstream_timeout 时间内没有收到上游服务的完整响应。
排查顺序建议如下：

1. 先在网关上执行 `xros-cli upstream health` 查看上游健康状态与实时延迟。
2. 检查 upstream_timeout 的当前值，确认它是否大于上游 P99 延迟。
3. 用 `xros-cli trace --last-error` 抓取最近一次失败请求的完整链路耗时。
4. 如果上游本身正常，检查中间网络是否存在丢包或 MTU 不匹配。

如果 E1042 是偶发的（每小时少于 5 次），通常属于正常网络抖动，可以忽略。
如果是持续性出现，请优先排查上游服务，而不是一味调大超时时间。

### E3008 详细说明

磁盘空间不足通常由日志堆积引起。系统默认保留 30 天日志，
但如果 log_level 被设为 debug，日志体积可能增长 10 倍以上，需要相应缩短保留期。

可以执行 `xros-cli storage usage` 查看各目录占用，用 `xros-cli storage rotate` 手动触发轮转。

## 5. 硬件指示灯

前面板共有 5 个指示灯：PWR（电源）、SYS（系统状态）、WAN（上行链路）、LAN（下行链路）、ALM（告警）。
SYS 灯绿色常亮表示系统正常运行，橙色闪烁表示固件升级中，红色常亮表示系统故障。
ALM 灯亮起时，请登录控制台查看具体告警内容。
