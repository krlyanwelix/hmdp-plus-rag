# XR-2000 版本变更记录

## 3.2.1（2025-11-18）

- 修复：集群模式下会话令牌吊销列表偶发不同步的问题。
- 修复：`upstream_timeout` 设为小于 5 秒时，重试逻辑会跳过退避直接重发。
- 优化：日志轮转改为按大小和日期双条件触发。

## 3.2.0（2025-10-02）

- 新增：支持 OIDC 单点登录，可通过 `security.oidc.enabled` 开启。
- 新增：`GET /api/v1/upstream/health` 接口，返回各上游的实时延迟分位数。
- 变更：默认 `upstream_timeout` 从 60 秒下调为 30 秒。
- 变更：默认 `log_level` 从 warn 上调为 info。
- 移除：不再支持 Redis 6.x。

升级注意：本次变更了两个默认值。如果你此前依赖默认的 60 秒超时，
升级到 3.2.0 后必须显式在配置文件中写回，否则会出现超时提前触发。

## 3.1.4（2025-08-21）

- 修复：E3008 磁盘告警在日志目录为符号链接时不生效。
- 优化：连接池回收策略改为惰性回收，降低空闲时的 CPU 占用。

## 3.1.0（2025-06-15）

- 新增：基于 eBPF 的流控引擎，替代原有的 netfilter 实现，吞吐提升约 35%。
- 新增：深度包检测（DPI）支持，需要额外授权。
- 变更：启用 DPI 后建议把并发连接数控制在 3000 以内。

## 3.0.0（2025-03-08）

- 首个 XROS 3.x 正式版，仅支持 XR-2000 硬件。
- 全新 Web 控制台，管理 API 从 v0 迁移到 v1，接口路径有破坏性变更。
- 配置文件从 `/opt/xros/gateway.conf` 迁移到 `/etc/xros/gateway.yaml`。

从 XROS 2.x 升级到 3.x 无法原地完成，需要重装系统并手动迁移配置。
