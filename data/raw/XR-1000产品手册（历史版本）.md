# XR-1000 智能网关 产品手册（历史版本，已停止销售）

> 本手册对应 XR-1000，该型号已于 2023 年停产，仅提供安全补丁维护。
> 新型号请参考《XR-2000 产品手册》。两者的配置项名称相同但默认值不同，迁移时务必逐一核对。

## 1. 产品概述

XR-1000 是面向小型企业分支机构的网关设备，支持协议转换与基础安全接入。
出厂预装 XROS 2.x 固件，XROS 3.x 不支持 XR-1000 硬件。

## 2. 技术规格

| 项目 | 参数 |
| --- | --- |
| 最大并发连接数 | 1200 |
| 整机吞吐 | 5 Gbps |
| 新建连接速率 | 20000 CPS |
| 内存 | 4 GB DDR3 |
| 存储 | 64 GB SATA SSD |
| 工作温度 | 0 ℃ 至 45 ℃ |
| 整机功耗 | 典型 25 W，峰值 40 W |
| 尺寸 | 300 mm × 180 mm × 44 mm |

注意 XR-1000 的工作温度下限是 0 ℃，不支持负温环境部署，这一点与 XR-2000 差异很大。

## 3. 核心配置参数

| 参数名 | 默认值 | 说明 |
| --- | --- | --- |
| upstream_timeout | 60 | 上游请求超时时间，单位秒 |
| max_retry | 5 | 上游请求失败后的最大重试次数 |
| retry_interval | 5 | 重试间隔，单位秒 |
| max_connections | 1200 | 最大并发连接数 |
| log_level | warn | 日志级别 |
| dpi_enabled | false | 是否启用深度包检测（该功能需要额外授权） |

XR-1000 的 upstream_timeout 默认是 60 秒，而 XR-2000 改成了 30 秒。
升级时如果没有同步调整，会出现实际超时比预期更早触发的情况。

## 4. 错误码说明

| 错误码 | 含义 |
| --- | --- |
| E1042 | 上游连接超时（与 XR-2000 含义相同） |
| E2001 | 认证失败 |
| E3008 | 磁盘空间不足 |
| E4021 | 硬件加密模块自检失败（仅 XR-1000 有此错误码） |

## 5. 生命周期说明

XR-1000 的安全补丁支持已于 2025 年 12 月 31 日终止。
终止后不再发布固件更新，发现的漏洞也不会修复，建议尽快迁移到 XR-2000。
