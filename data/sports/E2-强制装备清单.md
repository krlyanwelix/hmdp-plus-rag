# 2026 野径越野挑战赛 强制装备清单

> 赛事编号 E2 ｜ 执行标准：2026 届 ｜ 检查方式：赛前检录 + 随机抽查

## 一、全程强制装备（30 公里与 50 公里均需）

| 装备 | 要求 |
| --- | --- |
| 号码布 | 组委会发放，须佩戴于身前可见位置 |
| 手机 | 电量 ≥ 80%，存有组委会紧急联系电话，全程开机 |
| 哨子 | 无珠哨或带珠哨均可，须能正常发声 |
| 救生毯 | 铝膜救生毯，未拆封，尺寸不小于 130cm × 210cm |
| 水具 | 容量不少于 1 升的水袋或水壶 |
| 急救包 | 含创可贴、弹性绷带、碘伏棉签 |
| 反光标识 | 背包或衣物上有反光条，夜间可辨识 |

## 二、50 公里组附加强制装备

| 装备 | 要求 |
| --- | --- |
| 头灯 | 亮度 ≥ 200 流明，配一副备用电池 |
| 冲锋衣 | 防水指数 ≥ 5000mm，可收纳，禁止一次性雨衣替代 |
| 长袖保暖层 | 抓绒或羊毛材质，重量 ≥ 200g |
| 能量食品 | 热量不低于 800 千卡 |

## 三、建议装备（非强制）

- 登山杖（30 公里组建议单杖，50 公里组建议双杖）
- 防沙套、越野跑鞋（不建议穿路跑鞋）
- 盐丸、电解质片
- 备用袜子

## 四、检查方式

- 赛前检录：07:00（50 公里）/ 08:00（30 公里）前完成，逐项核验
- 检查点抽查：CP1、CP2（50 公里组含 CP3）随机抽查，抽查率不低于 20%
- 缺少任一强制装备：当场记录，取消参赛资格，报名费不退
- 装备损坏可现场更换，但须经裁判确认并登记

## 五、寄存与转运

- 起终点设存包区，凭号码布寄存，不接受贵重物品
- 50 公里组在 CP2（26 公里处）设转运包，可存放替换衣物与补给
- 转运包须使用组委会提供的专用袋，赛前 06:00 前交至转运区

## 六、装备违规的处罚

- 首次抽查缺少装备：取消成绩，收容退赛
- 使用一次性雨衣替代冲锋衣：视为缺少强制装备
- 借用他人装备通过检查：双方均取消成绩并禁赛两年

## 七、赛事当日气温参考

- 从化 11 月下旬常年气温 12-22℃，山区清晨可低至 6℃
- 赛道海拔落差约 1200 米，50 公里组累计爬升约 2100 米
- 建议按「早晚保暖 + 午间排汗」两层思路准备
